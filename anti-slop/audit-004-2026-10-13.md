# Anti-Slop Audit #004: UI Copy, Data Clarity, and Role States

> **Date:** 2026-10-13  
> **Scope:** Login, shared navigation, Target Dokter, Jadwal Kunjungan, Pelaksanaan Kunjungan, and manager campaign views.  
> **Method:** Source scan of Blade/CSS/JS plus browser checks at desktop and 390px mobile for MR and RSM views. No UI files were changed.

## Findings

### 1. [HIGH] Manager summary fails silently

* **Rule:** `R-27` (UI States)
* **Location:** `resources/js/pages/call-lists.js`, `loadExecutiveSummary()` around line 1498.
* **Reason:** The summary section starts hidden and the catch only writes to `console.warn`; when its request fails, managers see no summary and receive no visible error or retry action.

### 2. [HIGH] A zero-doctor national campaign is presented as a regional RSM directive

* **Rule:** `C-1` (Intentionality) and `C-3` (Content-Driven Composition)
* **Location:** `resources/js/pages/call-lists.js`, around lines 1265 and 1371; `app/Services/ManagerialCampaignService.php`, around line 57.
* **Reason:** `doctor_count === 0` is used to infer a Regional directive. MM campaigns can have no doctors and use `district_name: Nasional`, so their type and “under RSM coordination” copy become inaccurate.

### 3. [HIGH] Zero denominator is rendered as a measured 0% result

* **Rule:** `R-17` (Data & Numbers)
* **Location:** `app/Services/ManagerialCampaignService.php`, around lines 279-288; `resources/js/pages/call-lists.js`, around lines 1450-1465.
* **Reason:** A Regional row with no target doctors is serialized as `0/0` and `0%`. Reach is undefined when there is no denominator; the display should use a not-applicable state instead of implying failed performance.

### 4. [MEDIUM] Visible terminology still contradicts the agreed UI wording

* **Rule:** `R-20` (Visual Identity and consistency)
* **Location:** `resources/js/pages/call-lists.js`, around lines 1345, 1379, 1432, 1435, and 1570.
* **Reason:** The UI still shows “Regional Executive Summary”, “Obat Fokus”, “Kunjungan produk fokus”, “Cakupan Kunjungan”, and “Cakupan:”. These conflict with the request to remove Executive wording, use “produk prioritas”, and omit coverage from the campaign detail.

### 5. [MEDIUM] Call Actual loses its required page-term subtitle after load

* **Rule:** `R-20` (Consistency)
* **Location:** `resources/views/call-actuals/index.blade.php`, around line 12; `resources/js/pages/call-actuals.js`, around line 252.
* **Reason:** The initial “Call Actual” subtitle is replaced wholesale with “Hari ini - [tanggal]”. The rendered page therefore no longer identifies the PDF/domain term, unlike Target Dokter and Jadwal Kunjungan.

### 6. [LOW] Two equivalent actions appear together in the no-plan state

* **Rule:** `C-3` (Content-Driven Composition)
* **Location:** `resources/views/call-actuals/index.blade.php`, around lines 56-64.
* **Reason:** The empty state shows “Catat Kunjungan” and the adjacent secondary action “Kunjungan di Luar Rencana”; both open the same form, adding visual weight without adding a distinct action.

## Browser Notes

* Checked MR Target Dokter and Jadwal Kunjungan at desktop; both empty states repeat their page-header primary action.
* Checked Pelaksanaan Kunjungan at 390px; mobile navigation works and the no-plan state visibly duplicates its action.
* Checked RSM monitoring at desktop and 390px; the executive wording, coverage KPI, and zero-denominator row are visible. The district table scrolls within its responsive wrapper.
* No horizontal page overflow was apparent in the checked mobile views. Other roles, loaded data combinations, and failure-state screenshots were not exercised.

## Follow-up: Fixes Applied

All six findings were addressed in the current worktree:

1. Added an inline summary failure state with a retry action; unsuccessful HTTP responses and invalid payloads now reach that state.
2. Campaign type and scope copy now use `district_name` (`Regional` or `Nasional`), not a zero doctor count.
3. Summary and district reach show `-` when the target denominator is zero; no zero-width progress indicator is rendered.
4. Removed visible Executive wording and replaced the audited labels with `Produk prioritas`, `Dokter target dikunjungi`, and `Wilayah`.
5. Kept `Call Actual` in its page subtitle and moved the current date into a separate line.
6. Removed the duplicate empty-state action; `Kunjungan di Luar Rencana` remains the single action.
